# online store
 ## Ведение в ООП

были реализованы классы с раширеной логикой и приватным атрибутом `Product` и `Category`
добавден класс CategoryIterator - Итератор для перебора продуктов

## Реализованно:

- Класс `Product` содержит:
  - название (name)
  - описание (description)
  - цену (price)
  - количество (quantity)

- Класс `Category` содержит:
  - название (name)
  - описание (description)
  - список продуктов (products — список объектов `Product`)
  - атрибуты класса:
    - `category_count` — общее количество категорий
    - `product_count` — общее количество продуктов во всех категориях

- Класс `CategoryIterator` содержит:
  - итератор

- Класс наследник `Smartphone(Product)`

- Класс наследник `LawnGrass(Product)`

- Абстрактный класс `BaseProduct`

- класс-миксин `LoggerMixin`
